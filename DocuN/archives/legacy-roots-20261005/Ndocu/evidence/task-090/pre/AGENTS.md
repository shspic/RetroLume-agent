## 规则读取

- 全部 Agent 读取公共提示词库下的 `docu/AGENTS.MD`。
    
- 编排 Agent 同时读取公共提示词库下的 `docu/WORK.MD`。
    
- 编排 Agent 按当前阶段读取公共提示词库的 `Ndocu/prompts/`，使用其中的00—09提示词；仅启用本次授权涉及的阶段。
    
- 任务卡模板读取公共提示词库的 `Ndocu/TASK_TEMPLATE.md`。
    
- 执行 Agent 读取本入口、公共规则及任务卡指定的最小充分上下文，不加载全部阶段提示词。
    

## 路径与保存位置

本项目采用“公共提示词集中引用”模式。公共规则中要求在项目内读取AGENTS、WORK、任务模板及阶段提示词的地方，按上述路径读取，不要求复制这些公共文件。

除此之外，规则中的项目相对路径均以当前目标项目根目录为基准：

- 正式需求、架构、执行状态、CHANGE及正式报告保存在本项目的 `docu/`。
    
- 已填写任务卡、执行结果、证据、交接和实验保存在本项目的 `Ndocu/`。
    
- 源码、资源及正式配置保存在本项目相应目录。
    
- 用户明确指定的外部开源参考目录和错误经验库位置保持不变。
    

公共提示词库作为只读规则来源；开发本项目时，不向其中写入项目产物或修改公共规则。修改公共提示词库须另有对应任务授权。

任务卡须写明实际项目根目录、本入口及所需公共规则的绝对路径，使执行者可以独立读取。

## 更新与访问

编排 Agent 在本项目执行文档中记录所采用的公共规则版本或修改时间。公共规则更新时，先核对对当前任务的影响，同步相关任务和交接；不把旧窗口未读取的新规则当作已经生效。

同一窗口已读且仍有效的内容不重复全文加载，变化或缺失时补读。无法访问公共提示词库时明确说明；由可访问的 Agent 提供必要规则副本或完整内容，不假装已经读取。

本入口只维护项目定位、规则来源及路径映射，不复制公共规则正文。更高层指令和工具权限始终有效。
