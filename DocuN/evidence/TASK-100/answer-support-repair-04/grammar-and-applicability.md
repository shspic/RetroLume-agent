## 完整接受语法

外围只移除 Python `str.strip()` 空白；可有一个终止句号 `。` 或 `.`，移除后再去尾部空白。数字 N 为 ASCII `-?[0-9]+(?:\.[0-9]+)?`；不接受正号、指数、小数缺整数部或其他数字写法。负数作为明确数值仍交由原有确定比较，不当作自然语言否定。

参考单位为既有受支持单位时，整个文本为 `Q (SEP AUX)*`：

- Q 完整匹配 `N 空白* U`。U 只能为 `m/min`、`m/s`、`米/秒`、`米每秒`、`min`、`分钟`、`秒`、`s`、`m`、`米`；三个带斜线的单位容许斜线两侧空白。单位归一化及量纲/换算保持原映射。先识别全文语法，再比较单位和值，不能按参考量纲筛选候选。
- SEP 为 `,`、`，`、`;`、`；`，两侧可有空白。空 AUX 不接受。
- AUX 或为八个完全相等的固定短语：`先统一秒`、`先统一时间单位`、`先换算秒`、`分钟乘60`、`单位与数量级合理`、`单位与数量级正确`、`数量级合理`、`数量级正确`；或为完整时间等式 `N 空白* (分钟|min) 空白* = 空白* N 空白* (秒|s)`。时间数均须非负，Decimal 精确验证分钟×60=秒。短语内部不自动删空白；没有任意前缀、后缀、解释或关键词兜底。

参考无单位时，仅接受 `(?:约 空白*)?N`，没有 AUX。未知参考单位保持未检验。程序 exercise_type 保持跳过答案量值识别；即使原文是明确数值也不执行程序或宣称程序答案核定。

Q 是整个回答首部的明确值断言，AUX 是封闭的肯定辅助说明，不作为第二个答案量值。根量值不跨句查找，不取第一个/最后一个搜索结果。分钟等式的精确验证只验证这个辅助命题；固定合理/正确短语不能单独证明其理由，开放维度仍沿原有低信任反馈和独立性纪律。
