TASK-094 / R-088 活动工作区最小文本线框与状态文案
性质：设计线框，不是实现截图；供下一完整实现卡直接采用。
约束：不显示尚不存在的按钮；低信任正文纯文本展示；金额与时间按持久字段口径显示。

一、导航（复用现有左侧栏）
▤ 我的资料            （现有，不动）
▦ 学习活动            （新增，可选中；描述：活动范围、预算与运行结果）
  模拟面试  尚未接入   （保持现状）

二、活动工作区列表视图（选中「学习活动」时）
标题：学习活动
说明：每次活动限定资料范围与有限预算；这里查看活动、预算与每次运行的事实结果。
动作：＋ 新建活动（仅当 capabilities 显示可用时出现）

列表行（由活动事实派生，按 created_at 倒序）
  活动摘要（派生标签，非持久字段）：由「资料A」「资料B」等 N 份资料组成
  状态徽标：空闲 / 运行中 / 已取消
  剩余请求：x / y   费用已预扣：a / b
  创建于 …   最近更新 …

空状态文案：
  还没有学习活动。
  新建活动只确定资料范围与有限预算，不会立即产生任何模型调用。
  学习动作入口将在后续版本接入；当前可查看、可取消。

加载状态：正在读取活动…
错误状态：无法读取活动列表。（按钮：重试）
  连接中断时附加：刷新与断线只会重新读取，不会重发任何业务动作。
能力分层状态（互不影响）：
  存储未就绪（storage_not_ready）：活动数据表不可用，本页只显示此状态；资料功能不受影响。
  新建未开放：模型标识或活动额度尚未在本地配置完成（见本地配置文件）；只读与取消不受影响。
  继续未开放：模型密钥尚未在本地配置；新建与只读、取消不受影响。

三、活动详情视图
标题行：活动摘要标签   状态徽标   动作：
  [取消活动]（仅状态非已取消时出现；点击需一次明确确认）
  [刷新]
范围区：
  资料范围 N 份，范围修订 r
  · 资料标题（格式 版本 v）   当前有效 / 已失效（资料已被替换或移除）
  说明：活动使用选定资料当时的版本快照；替换资料后旧成果只读保留但正文可能不可回查。

预算区（四账分开，预扣口径与不确定事实分开展示）：
  模型请求：已预扣 x / 上限 y（剩余 y-x；预扣不因取消或失败退还）
  费用：已预扣 a / 上限 b（单次预留 c；单位由本地配置声明）
  时间：上限 M 秒 · 已结算 S 秒 · 当前预留 R 秒 · 可用 M-S-R 秒
    说明：运行中的 R 是预留，结束时按本机实际耗时（单调测量、向上取整）结算；账本只保留最近一次结算，
    不提供逐窗口历史。本机单窗口有硬性停止（单调时限）；账本中租约与到期的判定使用系统时钟，
    系统时间被调整时只影响「能否开新窗口」的判定口径，不改变已发生的本机停止事实。
  工具次数：未配置（本版本不执行工具） / 已预扣 t / 上限 u
  期限：到期时间 …（已取消时显示取消时间）

运行状态区（活动为运行中时）：
  运行中（账本事实）：账本显示该活动存在一个执行窗口，账目最长 W 秒；结束后按持久事实更新。
  最后更新：…（页面接收时间）
  执行存活未知：账本无法证明本机执行进程是否仍在运行；本页不据此推断「仍在运行」或「已中断」。
  说明：页面断开不会取消本机执行，也不会重发；时间账中的已结算秒数按实际执行的单调测量累计。

操作列表（按操作键排序，游标分页）：
  行内容：操作键 · 类型（模型调用 / 本地计算） · 状态 · 时间 · 失败原因（如有） · 正文可用性
  状态文案（与持久事实一一对应）：
    已预留，尚未确认开始发送（reserved）
    已确认开始，等待结果提交（dispatched）
    已提交，正文可回查（committed_current）
    已提交（活动已取消，仅供历史查看）（committed_history_cancelled）
    已失效，活动范围已变化（invalidated_scope_changed）
    已失效，资料已被替换或移除（invalidated_source）
    结果未知，可能已发出；不会自动重发（unresolved，state=unknown）
    进行中，结果尚未提交（unresolved，state=reserved/dispatched）
    已结束但无正文记录（terminal_without_payload）
  失败原因文案（示例映射，实际为有限白名单）：
    deadline_exceeded → 等待模型响应超时，远端是否已执行未知
    delivery_unknown / transport_unknown → 发送结果未知，不会自动重发
    remote_http_429/5xx → 远端拒绝或暂不可用
    request_not_sent → 确认未发出；该请求已计入次数与费用预扣
    record_denied / record_unconfirmed → 结果未能提交到本地账本
    cancelled / executor_lost → 执行被取消或执行者失联（保守未知）
    其他未分类 → 内部错误（未分类）

操作详情（点击行展开或右侧面板）：
  模型调用：返回模型（如有） · 结束原因（如有） · 提示/补全 token · 提交时间
  正文：纯文本展示（不执行其中的 HTML/脚本）；无效或失效时显示原因占位：
    正文已失效（活动范围已变化 / 资料已被替换），不再提供
    尚无正文（结果未提交或未知）

四、新建活动视图
表单：
  资料范围（多选，仅列出当前有效资料；待核对 PDF 不可选）
  额度预览（只读，来自本地配置，不可在界面修改）：
    期限、模型请求上限、费用上限与单次预留、时间上限、工具（未配置）
  说明：创建不产生任何模型调用；预算为上限性质，达到上限会拒绝新动作。
  按钮：[创建活动]（双击不会重复创建；页面刷新后的再次创建是一次新的明确意图）

失败文案：
  所选资料已在别处被替换，请刷新后重新选择
  该资料尚未完成核对或已被移除
  活动额度尚未配置，无法创建（附配置位置提示）
  已创建（重复提交时直接进入该活动）

五、显式继续（从成果继续）
仅当某条模型成果状态为「已提交，正文可回查」时，该行出现：
  [从该成果继续…]
展开表单：
  继续输入（用户补充文本，长度上限 L）
  本次动作将消耗：1 次模型请求与 1 次单次费用预留；当前剩余 x / b
  按钮：[发出并等待]（同一意图内重复提交不会产生第二次调用）
运行中展示：本动作执行中，最长约 W+余量 秒；可刷新查看事实。
响应丢失文案：本动作结果未确认；正在按持久事实核对（不会自动重发）。核对结论：
  已找到操作记录与正文 → 直接展示；
  确认未开始 → 可显式再次发起（将生成新的操作键）。
预算不足或不可继续时的文案：
  剩余请求不足 / 费用预留不足 / 活动已取消或过期 / 该成果类型仅可只读（工具结果）
  上一成果已失效，不能作为继续依据（显示失效原因）

六、上次动作未确认（刷新或断线后的恢复）
出现条件：意图台账中存在状态为「已提交或未确认」的意图（新建或继续），或页面收到过响应丢失。
横幅文案：上次动作（新建/继续）结果未确认。原请求可能在途；刷新与断线不会自动重试，也不会生成新键。
条目内容：动作类型 · 活动/操作键（短格式）· 发起时间 · 当时选择的资料或输入摘要（用户自己的文本）
三个显式操作（均为按钮，绝不自动执行）：
  [核对]：只读检查该活动的操作记录与运行窗口；
    找到事实 → 展示结果并从台账标记为已确认；
    未找到开始的持久迹象 → 显示「尚未发现该动作开始的记录；即使原请求稍后到达，同一操作键也至多执行一次」。
  [重新提交同一意图]：以原键重发一次；服务端同键至多产生一次执行，不会重复计费计数。
  [放弃]：从台账移除；不再使用该键；如要发起请用新的明确意图（新键）。
核对期说明：核对只轮询读取；不因等待超时自动升级为任何写入。

七、取消确认与结果
确认文案：取消后不会开始新的动作；正在运行的本机执行会在其自身窗口内停止；
  已发往远端的调用无法撤回；已预扣的请求次数与费用不退还。
完成后：状态徽标「已取消」；时间账按真实结算保留。

八、通用规则
页面任何自动刷新都只做读取（GET），不触发业务动作。
每个面板独立显示自己的「最后更新」时间；不将两个不同时刻的响应合并成单一承诺视图。
所有 hash、内部编号、进程与路径信息不出现在界面。
意图台账保存在本机浏览器存储中，只含业务键与用户自己输入的文本，不含密钥或任何授权物；
它是恢复提示，不是授权，清除它不影响服务端任何行为。
