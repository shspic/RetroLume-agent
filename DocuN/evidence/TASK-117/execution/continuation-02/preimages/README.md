# RetroLume 本地工程入口

本目录为 RetroLume 本地工程，提供资料、学习、文字面试、低信任记忆和隔离只读恢复入口。STEP018 的混合检索集成仍在 TASK117 合成候选收口中；实际验收状态以 [执行动态文档](DocuS/执行动态文档.MD) 为准。合成传输与真实供应商语义分别验证。

TASK117 S02 当前为部分交付，尚未形成稳定 S 候选，真实供应商调用仍关闭。面试须先开始场次，再明确确认资料索引。最新 014 源码已修正记忆资格的传递只读授权及删源触发器别名；本轮合成 source/compat 尚未应用该前向增量，后续获准接续须先核对并应用最小事务，再验证目录指纹，不能跳过检查启动。具体结果与待应用 SQL 见 [TASK117 结果](DocuN/results/TASK-117-result.md) 和 [最小前向修正](DocuN/evidence/TASK-117/execution/continuation-01/ordinary-db-fixes/pending-forward-repair.sql)。这不授权自动迁移用户库。

## 环境与依赖恢复

使用 Python 3.12、Node 24 和 npm 11。后端依赖由 `backend/requirements.lock` 固定；在 `backend/` 创建项目内 `.venv` 后执行：

```powershell
.\.venv\Scripts\python.exe -m pip install --only-binary=:all: -r requirements.lock
```

前端在 `frontend/` 使用精确 `package-lock.json`：

```powershell
npm.cmd ci --ignore-scripts --no-audit --no-fund
```

这些命令只重建项目内依赖，不升级锁版本。已安装包随自身发布的许可证与版权声明保留在项目内依赖目录；仓库不提交 `.venv` 或 `node_modules`。

## 本地配置与启动

设置两个互相独立、已存在的绝对目录：`RETROLUME_DATA_DIR` 与 `RETROLUME_BACKUP_DIR`。资料与备份可位于项目外，但它们是数据配置，不能指向外部源码。可参考 `config/local.env.example`，不要提交真实路径、连接串或密码。

若要连接既有本地 PostgreSQL，再在当前会话设置 `RETROLUME_DATABASE_URL`，或在 `config/database.local.json` 保存仅本机使用的私有配置（该文件已忽略）。应用不会自动创建数据库或迁移用户库。`deploy/initialize-materials.py` 仅供另行明确批准的新库首次初始化。模型调用需要完整配置和用户显式动作，读取、零费新建及刷新不会启动模型。

开发健康检查可在设置上述两个目录后运行：

```powershell
.\deploy\start-backend.ps1
```

访问 `http://127.0.0.1:8000/health`。`start-local.cmd` 会在数据库配置有效且容器镜像一致时启动既有本地容器；它只停止本次启动的容器和应用。构建后的前端由后端同源提供；开发前端可在 `frontend/` 运行 `npm.cmd run dev`，实际模型动作使用同源工作区。

## 活动与首次学习

活动配置参考 `config/activity.example.json`，在本机私有 `config/activity.local.json` 中分别配置活动限额和模型服务。示例占位值不会激活调用。服务密钥仅由配置指定的环境变量读取，不能填入目标、资料或浏览器。活动读取仅依赖存储层，零费新建需要活动限额层，首次学习及续问另需完整模型服务层。

模型能力默认关闭。旧词项入口保留 `learning.v1`，集成入口使用 `learning.v2`、`teaching.v3` 与 `interview.v2`，须同时配置混合检索。输出限额分别最多256、2048、2048，且不超过活动与服务上限。公开示例的0和占位值有意不可用，坏配置会显示对应原因。

在活动工作区选择就绪资料并新建活动，此时不产生模型费用。TXT/MD需为当前未删除版本，PDF需完成有效物理页核对；用户补充保留独立来源身份。检查资料范围、服务用途与四类账面限额，输入具体目标并勾选确认，然后点击“开始学习”。目标最多1024字和4096 UTF-8字节，不能通过目标授权路径、工具或范围外资料。

一次动作最多检查10个来源、合计5 MiB原件和512个候选片段，PDF最多50物理页。旧词项入口保持原有限行为。集成入口显式确认当前资料索引，再对本轮必要问题查询；512维向量与词项按固定规则合并，仍逐段核对当前原件。索引按每批最多4段预览次数和预留，缓存命中不重复索引。查询后还需一次模型时，先检查完整两次调用的次数、费用与时间余量；预览不替代服务器逐笔事务准入。同名歧义、证据不足和冲突保持可见，检索排序不证明结论正确。

`RETROLUME_INTEGRATION_CONFIG` 指向私有配置，结构见 `config/integration.example.json`。真实外发需要主控采用的激活回执、独立审核结果、价格原件、不可重绑的 OutboundGrant 和实际 source/version/revision/原件哈希及必要片段白名单。grant 的 `source_manifest_sha256` 绑定 `retrolume.outbound-sources.v1` 规范JSON摘要，清单另保留冻结设计样本摘要；不能以文件名或64位格式检查替代范围核对。provider密钥只在服务器环境，不能通过浏览器、资料或operator预览票据批准模型外发。当前TASK117的Q未启用。

成果从活动存储读取，展示答案或必要提示、确认目标、引用和能力限制。点击“查看引用”回查该版本的真实行段；PDF显示物理页并区分原文和用户补充。版本被替换或来源失效时明确不可用，不拿新版本替代旧引用。引用身份与位置合法不代表结论已独立证实，真实供应商的整体语义质量仍待获准样本验证。

从当前学习成果点击显式续问，输入问题并确认发送。它保留原目标，用新的受控操作重新检查范围、版本和预算；已有成果不被覆盖。普通模型成果保留原继续入口。模型文字只作文本显示，不执行HTML、脚本或工具。

## 刷新、取消与未确认动作

首次及续问会先在本机意图台账记录业务键和输入，再发送一次显式请求。刷新和切换只查询持久事实；正文不依赖本机缓存恢复。首次槽位由服务端稳定绑定目标和范围，双击或换客户端键不会产生第二个首次成果；异文会提示冲突，修改目标应显式续问或新建活动。

未确认横幅可能表示请求未到达，也可能表示服务器已执行。先点击核对；只有用户点击同键重试才会再发请求，已知持久操作仅返回事实。真实未知状态不自动换键或重发，也不自动退还预留。放弃仅移除本机意图，不取消服务器、不退款或删除已保存成果。

旧格式未确认意图继续可核对。意图台账损坏时暂停依赖恢复的新写动作，读取和两步确认取消仍可用；核对服务器事实后可通过浏览器站点存储工具修复或移除本机台账，此举不改变服务器状态。取消停止本机受监督后续执行，无法撤回已经发给远端的请求；保留已有有效成果及真实账面事实。

## 教学工作区

教学入口须显式配置 `teaching.profile` 及有限输出（1至2048）。旧v1/v2行为保留，v3消费当前混合检索及可选记忆身份。有限核算另需 `teaching.enable_calculation=true`、`activity_defaults.allowed_tools` 包含 `finite_calculate` 和有限工具次数上限；模型与工具额度独立。启动器不迁移用户库，本卡候选不能作为用户库升级许可。

先零费保存目标，再显式生成并接受路径。页面显示节点、前置和理由；获取练习后可先作答，也可单独查看提示或参考。保存作答不调用模型，评价是另一次明确动作。题目、参考、量规、已保存作答及纠错都按实际记录和摘要绑定；用户程序只作为文字推理题展示。

反馈区区分正确部分、实际错误、缺证据和原因假设，更新理由解释为何保留或前进。看过参考后的同题续答属于辅助观察；不同实例的独立作答和复测才可形成有限推进依据。纠错保留原事实并重新核对争议，不把用户声明当成已证实结论。

完整待发正文先存原生 IndexedDB，恢复摘要再存 localStorage，任一步失败都保留输入并阻止发送。跨标签页以存储互斥与数据库版本裁决。刷新和重开只读持久事实；未知结果只核对，不自动重发。确定失败后可显式新键重试。来源失效、取消或到期会停用相应动作，用户已保存文字仍有历史身份。

TASK-100续作02的唯一合成执行入口为 `backend/tests/fixtures/task100/runner.py`，真实运行只能在任务卡许可及累计预算内进行。它串行核验精确容器、两库最小权限、迁移反例、仓储、HTTP、原Windows监督链及最终构建浏览器，再独立收尾。provider仅作合成传输替代，证据不评价真实provider质量。产物与证据在 `DocuN/evidence/TASK-100/continuation-02/`，结果回传在 `DocuN/results/TASK-100-result.md`。

## 学习记忆

活动工作区中的学习记忆区只显示用户明确保存的记忆。用户自报、偏好、待练难点与当时有限观察分别标识；保存或修正不调用模型，不改写原始作答。教学成果旁先查看保存预览，再明确保存有限观察。

新活动默认不选记忆，每次最多明确勾选四个具体版本。教学v2把背景按有限容量装配，记忆不是正确性引用、长期掌握或工具授权。缺少memory_context或模型容量配置时拒绝背景调用，存储就绪后仍可查看、保存和撤销。memory_context默认null；采用时须显式给selected_items、max_memory_bytes、max_memory_chars、model_context_tokens、max_input_tokens_estimate、protocol_reserve_tokens、reserved_output_tokens、safety_tokens、estimate_policy=utf8_bytes.v1与model_identity。UTF8字节估算不是所有供应商的精确tokenizer，真实模型容量及条款在实际采用前核实。

修订、撤销、来源或原观察失效会停用旧选择活动的全部派生教学内容，继续须新活动明确重选，不自动切最新版。原始目标、作答、纠错保留历史身份。已选记忆的活动通过教学工作区使用背景，旧资料问答、普通继续或通用工具不绕行。

撤销预览说明全部版本与活动影响，先提交逻辑墓碑，再清理本条在线记忆正文。清理失败仍保持停用，刷新只读核对；明确重试使用原清单。它不删除资料、原始作答、活动历史或备份，不承诺撤回远端字节或擦除所有副本。010和角色最小权限只在获准目标执行，普通app无正文DELETE/TRUNCATE或拥有者权限，不关闭009不可变事实触发器。

本机IndexedDB只保存未确认动作及分身份草稿，不能代替服务端记忆。复制标签页由活跃owner互斥，修订冲突保留旧草稿，不自动改绑。刷新、轮询和重开均不重发命令或隐式清理。本次合成候选仍需编排安排稳定点独立审计；真实用户库、真实provider、部署和完整退出恢复没有因此获准。

## 数据退出、备份与只读恢复

“数据与备份”提供可读导出、当前时点恢复备份、隔离副本验证和明确的只读切换。导出中有普通文本、原 PDF、逐页提取、独立用户补充、教学和面试历史、模型正文及引用关系。备份保存请求、费用、工具、时间和预览的原账，包括未知预留；查看副本不会认领、退款或继续旧工作。

该功能保留013/R01，并新增014/R02的精确注册表和512维向量编码；新包按实际profile装载，不能混用或把包内DDL当可信定义。启动器不会迁移用户库、安装数据库或自动备份。真实用户库迁移、删除和切换须有对应授权。

私有配置使用 config/data-exit.local.json，结构见 config/data-exit.example.json。启用前配置专用快照连接和维护秘密，运行账户不加入控制owner或restore loader。固定主机slot显式声明 `schema_profile`：R01使用可信001—013，R02使用可信001—014；省略时只兼容R01。目标装载后撤销临时登录并永久封印只读，不能恢复执行、退款或索引旧工作。缺匹配slot明确不可恢复。

RETROLUME_DATA_DIR、RETROLUME_BACKUP_DIR、RETROLUME_RESTORE_ROOT、RETROLUME_CONTROL_ROOT 必须是已存在、互不包含的本机绝对目录。先检查原始路径，禁止 UNC、链接和重解析点。控制根须仅让当前 Windows 用户、SYSTEM 和管理员访问，并独立于资料、备份和恢复根。控制日志及 DPAPI 凭据留在此根，不进入任何数据包；更换 Windows 用户后不可解密时显示不可用。

手工导出或保存备份后，按原操作编号只读刷新进度。文件完成与操作收据分别记录；响应丢失不意味着保存失败，也不会自动再次生成包。下载小于 128 MiB 的包，大包从配置的本机备份目录取出。包是 ZIP_STORED，README.txt、texts、records、summaries 和 references 可独立查看。manifest 中的哈希证明字节一致，不证明可信作者或执行权。未提交的浏览器草稿仅能单独下载，不能冒充服务器提交记录。

“已请求取消”表示等待执行者收尾；只有准确工作已结束才显示“已取消”。进入文件发布、副本封存、资料墓碑或只读切换的不可逆准入后，取消会明确返回不可取消。已有文件、墓碑和选择事实按原编号核对。一次操作的总期限覆盖读取、复制、核验和完成收据；到期保留已发生结果并显示待核对，不能用进度或重试重新取得执行时间。服务重启后，在途操作的时限资格无法核对时保持只读查询。

恢复先上传并核对计划，再明确验证隔离副本。“副本已验证”表示当前应用仍使用原数据。选择“切换为当前只读数据”后，原工作按原监督链收尾，源数据冻结并保留，新副本只读；新副本不可用时不回退源库开写。若计划之后出现新的源删除，切换要求重新核对计划，围栏不会超时自动解除。缺停止证明或模式未知时只读核对原收据，不能宣布切换完成。

默认尊重当前已删除内容。按备份时点查看需要显式确认，可能显示旧包中的已删除内容，仅限隔离只读副本，源墓碑仍保留。删除资料先展示全部版本、依赖和共享原件影响，再提交明确确认。墓碑生效后回查不可用；只清理该条已无其他保留引用的准确原件，未确认时保持待清理。历史关系、原正文哈希、WAL 和旧备份保留，不承诺彻底擦除。

已保存记忆和派生历史在同一读取时点核对来源、事件与上游关系。资格失效、已删除或无法核对时隐藏正文，保留头、版本和原哈希。页面刷新只接受当前身份的新鲜回复；旧实例的材料、记录与未提交草稿不会自动迁到新只读身份。

本机 CLI 为 deploy/data_restore.py，可读取 capabilities 和 job，或显式 prepare plan、verify 副本；验证须带 confirm-readonly 和原业务键。应用关闭仅停止本次启动的准确进程和数据库，保留容器、卷、备份及失败证据。当前能力为数据退出、隔离恢复验证与永久只读查看，尚不完成恢复后继续学习、付费调用、工具和预览执行的全部要求。
